# 💡 Before you begin

### About

Clym Accessibility Tools has been designed to test the accessibility and compliance of websites. Accessibility Tools as a solution is deployed on-prem and the data is safely stored locally.

Some of the UI elements are provided with tooltips. If you need more information about how you can use a specific function, simply click the ![](https://lh7-rt.googleusercontent.com/docsz/AD_4nXdbH30wHcBiDX6EhVV23cgtmQ0R-sFqC2TDk6JwkCfQNflj0qRRDxAVTdkGac_DzbfYJC4mKBHLgSZZQyXC5oqCM6ZgbgJhWEz3Uyy-O_ckLuoa7Ft7_qwSdadB3jP4pnJz-hxz_A?key=_EQKB1eDe9ecbVZeBDg4Tw)Info icon (whenever available) and the corresponding information is displayed in a tooltip.

You can perform some actions by navigating either the left-hand side menu or the menu bar. For the sake of consistency, the procedures described herein start by accessing the left-hand side menu.

Some test cases consist of several steps, which require several expected results. These expected results require certain remediations. In some cases, one remediation can fix two or more issues. If even one remediation is not fixed, then the entire test case is considered failed.

In all further occurrences, Clym Accessibility Tools will be referred to as Accessibility Tools.

### Inclusive design

Accessibility Tools prioritizes inclusive design by offering comprehensive accessibility customization options that adapt to diverse user needs and abilities. Since accessibility requirements vary significantly among individuals, Accessibility Tools provides extensive interface modification capabilities including:&#x20;

* Adjustable font sizes
* High-contrast color schemes&#x20;
* Keyboard navigation alternatives
* Screen reader compatibility
* Motor accessibility features

Users can personalize their experience through granular control over visual elements, audio feedback, input methods, and interaction timing to create an environment that accommodates visual, auditory, cognitive, and motor impairments. Built with WCAG compliance standards as the foundation, the application goes beyond baseline requirements to deliver a truly adaptive interface that empowers users to configure their optimal working environment, ensuring equal access to functionality regardless of individual accessibility needs.

You can access this feature by going to Settings>Accessibility. You can read about this feature [here](../user-guide/settings/accessibility-profiles.md).
