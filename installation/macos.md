# 🖥️ MacOS

### First time installation

1. Download the Accessibility Tools installer file from the official [website](https://www.clym.io/products/accessibility-tools)
2. Run the installer

<figure><img src="../.gitbook/assets/image (75).png" alt=""><figcaption></figcaption></figure>

3. Once the install is completed, you can find the app in the launchpad and open it. It is now ready to use.

### Uninstall

1. Go to your Applications folder and find the Accessibility Tools app.

<figure><img src="../.gitbook/assets/image (76).png" alt=""><figcaption></figcaption></figure>

2. Right click on the app name and select Move to Bin, but make sure you have quit the app before performing this step

<figure><img src="../.gitbook/assets/image (77).png" alt=""><figcaption></figcaption></figure>

3. From your Finder screen, press Cmd + Shift + G and navigate to _\~/Library/Application Support_

<figure><img src="../.gitbook/assets/image (78).png" alt=""><figcaption></figcaption></figure>

4. Identify the _Accessibility tools_ folder, right click and move it to the Bin

<figure><img src="../.gitbook/assets/image (80).png" alt=""><figcaption></figcaption></figure>

5. Next, from the same Finder window, using Cmd + Shift + G again, navigate to _\~/Library/Logs_

<figure><img src="../.gitbook/assets/image (82).png" alt=""><figcaption></figcaption></figure>

6. Identify the _Accessibility tools_ folder, right click and move it to the Bin

<figure><img src="../.gitbook/assets/image (83).png" alt=""><figcaption></figcaption></figure>
