# 🐧 Linux

1. &#x20;Download the .AppImage file from the link above
2. Make the setup file an executable by opening the terminal where the file was downloaded and running:\
   `chmod +x a11y_setup.AppImage`
3. Run the app by running the following in the terminal:\
   `./a11y_setup.AppImage`

{% hint style="warning" %}
If you get this error: _FUSE: failed to open /dev/fuse: Permission denied_\
\- Run: `sudo apt install libfuse2`\
\- Then repeat step 3
{% endhint %}
