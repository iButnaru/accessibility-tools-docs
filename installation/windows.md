# 💻 Windows

## First time installation

1. Download the Accessibility Tools installer file from the official [website](https://www.clym.io/products/accessibility-tools).
2. Run the installer _.exe_ file.
3. In the **Choose Installation Option** wizard screen, select whether you want Accessibility Tools to be available to anyone who uses the computer or just to the account owner. \
   Click **Next**

<figure><img src="../.gitbook/assets/image (47).png" alt=""><figcaption></figcaption></figure>

4. In the **Choose Install Location** wizard screen, select the destination folder of the installation files. \
   Click **Next**.

<figure><img src="../.gitbook/assets/image (48).png" alt=""><figcaption></figcaption></figure>

5. Wait for the installation process to be completed.

<figure><img src="../.gitbook/assets/image (49).png" alt=""><figcaption></figcaption></figure>

6. Once the installation is completed, click **Finish**. If the **Run Accessibility Tools** box is ticked, the app will launch once the installer has been closed.

<figure><img src="../.gitbook/assets/image (50).png" alt=""><figcaption></figcaption></figure>

## How to uninstall

{% hint style="info" %}
Make sure you close the Accessibility Tools completely before uninstalling it.
{% endhint %}

1. Navigate to **Control Panel > Programs > Uninstall a program**.
2. Identify and select the Accessibility Tools in the list, then click **Uninstall**, or right click it and point to **Uninstall** in the shortcut menu.
3. In the **Accessibility Tools Uninstall** screen, click **Next**.

<figure><img src="../.gitbook/assets/image (51).png" alt=""><figcaption></figcaption></figure>

4. If Accessibility Tools is still running, you will be prompted to close it.

<figure><img src="../.gitbook/assets/image (52).png" alt=""><figcaption></figcaption></figure>

5. Wait until the uninstall is completed and click **Finish**.

<figure><img src="../.gitbook/assets/image (53).png" alt=""><figcaption></figcaption></figure>
