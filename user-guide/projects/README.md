# 📦 Projects

Projects represent a way to organize tests to ensure accessibility and compliance. Every time you run a compliance test, you do so inside a project, so you cannot run any compliance test without creating a project first.

A project can contain a multitude of tests, grouped according to various criteria:&#x20;

* **Test targets**: ARIA attributes, CSS, HTML, PDF etc.
* **Test type**: manual/automated
