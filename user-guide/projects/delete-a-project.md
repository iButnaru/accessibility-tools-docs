# 🗑️ Delete a project

To delete a project:

1. Click ![](<../../.gitbook/assets/image (89).png>) **Projects** on the left-hand side navigation pane.
2. Click the ![](<../../.gitbook/assets/image (96).png>) **Settings** button next to the desired project. On the shortcut menu, click **Delete project**.

<figure><img src="../../.gitbook/assets/image (99).png" alt=""><figcaption></figcaption></figure>

3. In the confirmation message, select the **Yes, I’m sure checkbox** and then click **Delete**.

<figure><img src="../../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>

{% hint style="danger" %}
* Deleting a project also completely erases all tests run under the project, so proceed with caution.
* Deleted projects cannot be restored.
{% endhint %}
