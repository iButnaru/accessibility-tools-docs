# ✏️ Modify a project

To modify a project:

1. Click ![](<../../.gitbook/assets/image (89).png>) **Projects** on the left-hand side navigation pane.
2. Click the ![](<../../.gitbook/assets/image (96).png>) **Settings** button next to the desired project. On the shortcut menu, click **Edit project**.

<figure><img src="../../.gitbook/assets/image (97).png" alt=""><figcaption></figcaption></figure>

3. Modify the project, as desired. For more information, see [Create a project](create-a-project.md).

<figure><img src="../../.gitbook/assets/image (98).png" alt=""><figcaption></figcaption></figure>

4. When finished, click **Save**.
