# 👤 User profiles

In **Accessibility Tools**, the user profile is required for running an audit and producing audit reports. The details of the user are included in the audit report.

We are currently working on a more complex version of the Accessibility Tools that will support multiple profiles, with different layers of access within the app. At this point, once you have added a profile, the **Add profile** button will no longer be available; in addition, the created profile cannot be deleted as this might be attached to an audit report and cannot be removed.&#x20;

{% hint style="success" %}
If you need to replace the existing user you should only modify the existing profile with the updated user information.
{% endhint %}

## Create a **user profile**

1. On the left-hand side navigation pane, go to  ![](<../../.gitbook/assets/image (12).png>) _**Settings**_ _**> Profile**_ and click **Add profile**.

<figure><img src="../../.gitbook/assets/image (14).png" alt=""><figcaption></figcaption></figure>

1. In the **Add profile** wizard, configure the fields, as follows:

* **Profile picture:** Upload a profile picture in the format indicated on the screen (either browse for it or use drag and drop).
* **First and last name** (mandatory): Fill in the details of the owner of the account.
* **Title** (mandatory): Enter the job title of the account owner (which will be displayed in the audit report).

<figure><img src="../../.gitbook/assets/image (15).png" alt=""><figcaption></figcaption></figure>

2. If you are representing a company and need these details recorded in the audit report as well, toggle the **I represent a testing/auditing organization** and fill in the company details.

<figure><img src="../../.gitbook/assets/image (16).png" alt=""><figcaption></figcaption></figure>

When finished, click **Create**&#x20;

3. The account profile is displayed under **Profiles** and will be available to selected when you [create an audit](../audits/create-an-audit.md).

<figure><img src="../../.gitbook/assets/image (17).png" alt=""><figcaption></figcaption></figure>

## Modify a user profile

To edit a user profile:

1. On the left-hand side navigation pane, go to ![](<../../.gitbook/assets/image (12).png>) _**Settings** >_ ![](<../../.gitbook/assets/image (13).png>) _**Profile**_.
2.  Click the ![](<../../.gitbook/assets/image (19).png>) **Profile settings** menu next to the profile that you want to modify and then click **Edit profile** on the shortcut menu.

    <figure><img src="../../.gitbook/assets/image (18).png" alt=""><figcaption></figcaption></figure>



3.  Update the profile details, as needed. For more information about the operations you can perform at this stage, see [Create a user profile](user-profiles.md#create-a-user-profile).\
    When finished, then click **Save**.

    <figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure>

## Delete a user profile

Currently, Accessibility Tools does not not support multiple profiles, so you cannot delete an existing user profile. Until multiple profiles are supported, the only available functionality is to [modify an existing profile](user-profiles.md#modify-a-user-profile).
