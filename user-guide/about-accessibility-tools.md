# ℹ️ About Accessibility Tools

### What is the Clym Accessibility Tools app?

The **Clym Accessibility Tools** solution is designed to audit websites and assess their compliance with WCAG standards and industry best practices. Using Accessibility Tools, you can evaluate websites page by page to identify areas that need improvement, ensuring content is accessible to people with disabilities, impairments and diverse accessibility needs. Once started, the process applies both automated and manual tests to the desired website and produces a report on the areas to improve.&#x20;

In all further occurrences, Clym Accessibility Tools will be referred to as Accessibility Tools.
