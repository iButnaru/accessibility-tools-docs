# ✏️ Modify a remediation

To modify a remediation:

1. On the left-hand side navigation pane, click ![](https://lh7-rt.googleusercontent.com/docsz/AD_4nXe2sNK7gdNDhoaSpJURhZv0s9jAsOFANn7utwUKTqDcBY63OhjHliRusxTRmzNd9i9cF_N2ohfZgqBA7q21yoIjLNbAi7mUzbN8bsITo5WqGdas4sBfxs6wQXqUbpJruh05lJE4?key=_EQKB1eDe9ecbVZeBDg4Tw) **Remediations**.
2. Select the remediation that you want to modify.
3. Click the ![](https://lh7-rt.googleusercontent.com/docsz/AD_4nXe8ogTV-782eGFQGI3UNbBK6CyPOhBDbhApxZwihyDrG0n8IxToMBEVk92GFtQRsTapnYIo3l4BhMUjwafpcHrAIlq_zJardfjBTmlq-Aqs4G1Q_R_fM5zYlydYAcYdZnEQCyqN?key=_EQKB1eDe9ecbVZeBDg4Tw) **Settings** button on the right-hand side of the table.
4. On the shortcut menu, click **Edit remediation**.

<figure><img src="../../.gitbook/assets/image (9).png" alt=""><figcaption></figcaption></figure>

5. In the **Edit remediation** screen, modify the details of the remediation, as needed. For more information about the fields in this wizard, see [Create a remediation](create-a-remediation.md).

{% hint style="warning" %}
Only user created remediations can be modified. If you haven't created a custom remediation, you will not be able to find the **Edit remediation** button.
{% endhint %}
