# 🗑️ Delete a Test Case

To delete a test case:

1. Go to ![](https://lh7-rt.googleusercontent.com/docsz/AD_4nXfN6K0nU016Q_ZmoQWOd2opQSvaB2hhcBsnuNrefbMsvyulwRNZQmDv2P7xAAgJfu28gD-8Yh8jYlXFxjW3g95RQQ_-QDWcVV5exbQ6roh_bJH75Lg0eC-L2aUoDI09cJbMZGNy?key=_EQKB1eDe9ecbVZeBDg4Tw) **Test cases** on the left-hand side pane.&#x20;
2. Select the test case you want to duplicate.
3. Click ![](https://lh7-rt.googleusercontent.com/docsz/AD_4nXe8ogTV-782eGFQGI3UNbBK6CyPOhBDbhApxZwihyDrG0n8IxToMBEVk92GFtQRsTapnYIo3l4BhMUjwafpcHrAIlq_zJardfjBTmlq-Aqs4G1Q_R_fM5zYlydYAcYdZnEQCyqN?key=_EQKB1eDe9ecbVZeBDg4Tw) **Settings** button on the right-hand side of the table.&#x20;
4. On the shortcut menu, click **Delete test case**.

<figure><img src="../../.gitbook/assets/image (74).png" alt=""><figcaption></figcaption></figure>

5. In the confirmation message, tick the _"Yes, I'm sure"_ box and click **Delete**

<figure><img src="../../.gitbook/assets/image (120).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
Only user created test cases can be modified or deleted. The built-in ones will always stay the same.
{% endhint %}
