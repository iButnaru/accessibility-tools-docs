# 📄 Duplicate a Test Case

To duplicate a test case:

1. Go to ![](https://lh7-rt.googleusercontent.com/docsz/AD_4nXfN6K0nU016Q_ZmoQWOd2opQSvaB2hhcBsnuNrefbMsvyulwRNZQmDv2P7xAAgJfu28gD-8Yh8jYlXFxjW3g95RQQ_-QDWcVV5exbQ6roh_bJH75Lg0eC-L2aUoDI09cJbMZGNy?key=_EQKB1eDe9ecbVZeBDg4Tw) **Test cases** on the left-hand side pane.&#x20;
2. Select the **test case** you want to duplicate.
3. Click ![](https://lh7-rt.googleusercontent.com/docsz/AD_4nXe8ogTV-782eGFQGI3UNbBK6CyPOhBDbhApxZwihyDrG0n8IxToMBEVk92GFtQRsTapnYIo3l4BhMUjwafpcHrAIlq_zJardfjBTmlq-Aqs4G1Q_R_fM5zYlydYAcYdZnEQCyqN?key=_EQKB1eDe9ecbVZeBDg4Tw) **Settings** button on the right-hand side of the table.
4. On the shortcut menu, click **Duplicate test case**.

<figure><img src="../../.gitbook/assets/image (74).png" alt=""><figcaption></figcaption></figure>

{% hint style="warning" %}
When you duplicate a test case, all the details of the original test case are pulled into the forms. For more information on the details in the modals, you can check the add new test case functionality by clicking [here](create-a-test-case.md).
{% endhint %}
