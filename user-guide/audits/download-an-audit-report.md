# 💾 Download an audit report

The audit report is available for you to download in two specific formats: as an in-progress audit and a as a completed one.

In the case of an in-progress audit, you can preview a PDF, HTML, or JSON version of the audit report as it is available at that point in time. The completed audit is the final version of the report.

#### To download an in-progress audit report:

1. On the left-hand side navigation pane, go to ![](<../../.gitbook/assets/image (141).png>) **Audits** and find the specific audit for which you want to see the report.
2. If the audit is still **in progress** (represented by an orange dot next to the audit name), click the ![](<../../.gitbook/assets/image (96).png>)**Settings** button and select **Preview report**.

<figure><img src="../../.gitbook/assets/image (156).png" alt=""><figcaption></figcaption></figure>

3. Select the format for the report (PDF, HTML, JSON) from the dropdown list and click **Download**.

<figure><img src="../../.gitbook/assets/image (157).png" alt=""><figcaption></figcaption></figure>

#### To download a complete audit report:

1. From the **Settings** menu, click the **Download** **report** button.

<figure><img src="../../.gitbook/assets/image (158).png" alt=""><figcaption></figcaption></figure>

2. &#x20;Select the format of the report from the dropdown list and click **Download**.

<figure><img src="../../.gitbook/assets/image (159).png" alt=""><figcaption></figcaption></figure>
