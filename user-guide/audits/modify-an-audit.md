# ✏️ Modify an audit

To modify an audit:

1. On the left-hand side navigation pane, click ![](<../../.gitbook/assets/image (141).png>) **Audits**.
2. Identify and select the Audit that you want to modify.
3. Click the ![](<../../.gitbook/assets/image (96).png>) **Settings** button next to the audit that you want to modify.&#x20;
4. On the shortcut menu, click **Edit options**.

<figure><img src="../../.gitbook/assets/image (144).png" alt=""><figcaption></figcaption></figure>

6. In the **Edit audit** screen, modify the audit as needed. For more information about the fields and the steps in this wizard, see [create an audit](create-an-audit.md).

<figure><img src="../../.gitbook/assets/image (143).png" alt=""><figcaption></figcaption></figure>
