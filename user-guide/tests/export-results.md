# 💾 Export results

After running a test, you can export data either as a test summary report or as a list of executed test cases and their details.

### 1. Export results as a Test Summary Report

* After [running a test](create-a-test.md), if you click the **Download PDF report** button in the test summary screen from the left-hand side pane, you are prompted to save the report to your computer in PDF format.&#x20;

<figure><img src="../../.gitbook/assets/image (56).png" alt=""><figcaption></figcaption></figure>

<figure><img src="../../.gitbook/assets/image (58).png" alt=""><figcaption></figcaption></figure>

* The report displays a summary of the test cases applied to your website, graphs by test type and status, but also based on the principles used in testing.
* The second component of the PDF test summary provides an overview of the test cases applied to each selected page with graphs on test status for each page, along with the specific URL for each of them.

<figure><img src="../../.gitbook/assets/image (60).png" alt=""><figcaption></figcaption></figure>

### 2. Export results as a Test Cases Report

After [running a test](create-a-test.md), click the ![](<../../.gitbook/assets/image (62).png>) **Export** button on the right-hand top side of the test cases list in the application to export the results of the recently run test.&#x20;

This report will be export in a CSV format and will provide details such as:

* Test type
* Test code (ID)
* Test case code (ID)
* Test case name
* Target HTML
* Target selector
* Test notes
* Test case description / instruction / steps
* Test case criterion
* Test case level
* Remediation code (ID)
* Remediation name
* Remediation description / instruction / steps
* Remediation category

These details are provided in table format, for all the test cases that were run for the respective test.
