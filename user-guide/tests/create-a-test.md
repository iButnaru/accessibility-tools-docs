# 📁 Create a test

Before creating a test, you must first [create a project](../projects/create-a-project.md). The **Start test** wizard screen is displayed as soon as you finish creating a project.

To create a test inside an existing project:

1. Go to ![](<../../.gitbook/assets/image (89).png>) _**Projects** >_ ![](<../../.gitbook/assets/image (96).png>) _**Settings > Start test**_.

<figure><img src="../../.gitbook/assets/image (104).png" alt=""><figcaption></figcaption></figure>

2. In the **Start test wizard** screen, fill in the fields, as follows:

* **Test name**: Give your test a meaningful name.
* **Environments**: Displays the environment you added when [defining a project](../projects/create-a-project.md). If you added more environments, select the desired one from the list.
* **Exploration notes**: Enter some details on the core functionalities of the website.
* **Variety of web page types**: Enter details on the different varieties of web page types.

When finished, scroll down and click **Continue**.

<figure><img src="../../.gitbook/assets/image (105).png" alt=""><figcaption></figcaption></figure>

2. Under **Structured sample web pages**, select the desired web page that you want to test. The pages available at this stage are the ones that function as templates for other pages on the website - for example, a product list page.\
   If you want to add more, click **Add another page**. You can remove any page you add at this point by clicking ![](https://lh7-rt.googleusercontent.com/docsz/AD_4nXd5Y5hLzhFMHRG7c2fnnnnQk3uJOULRdX1wXSH7ERu8zCS4lyA_HVuhAA77mGnQOwJhmaoxoenLlgDXNEfzgIH7zXH9OlJTcALVJR90-9a0pArz1na00yVOQmhfmsh4Gep0ZrCIxw?key=_EQKB1eDe9ecbVZeBDg4Tw)**Delete** next to it. \
   When finished, click **Continue**
3. Next, you can randomly select website pages to test. Click **+Add another page** and select one of the available options to run a test on multiple pages. You can remove any page you add at this point by clicking ![](<../../.gitbook/assets/image (106).png>)**Delete** next to the desired sample. \
   When finished, click **Create**.
4. The test results are displayed under **TEST CASES**. For more information on navigating the test results, see [View and act on test result](view-and-act-on-test-results.md)[s](view-and-act-on-test-results.md).

{% hint style="warning" %}
Depending on the structure of the web pages, the test may take a while to run. When finished, the newly-created test is displayed.&#x20;
{% endhint %}
