# 📔 Tests

Tests are the way in which Accessibility Tools verifies if a website is compliant and accessible. A test consists of a suite of [test cases](../test-cases/), which verify one or more test targets. You can create, modify and delete tests.&#x20;

To run a test, first you need to [create a project](../projects/create-a-project.md), as tests are run inside projects.&#x20;
